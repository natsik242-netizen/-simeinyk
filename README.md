# Сімейник

Перший MVP мобільного застосунку для iOS та Android.

## Що вже є
- Головний екран "Сьогодні"
- Профіль користувача
- Кілька сімей
- Діти
- Тварини
- Автомобілі
- Календар
- Здоров'я
- Документи
- Платежі
- Базовий таймер сну

## Запуск
1. Встановіть Flutter SDK.
2. У каталозі проєкту виконайте:
   flutter pub get
   flutter run

## Наступні кроки
- локальне збереження
- авторизація
- права доступу
- сповіщення
- синхронізація
- захищене сховище документів
